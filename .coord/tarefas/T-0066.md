# T-0066 — Consumidores dos eventos da Integração nos módulos donos

## Onde
**Local.** Lacuna achada pelo modulo-core em 02/11 (R-20261102-125557). Com o A7, o Hub aplica o lote e publica `integracao.<entidade>.atualizado@1`, mas faltam consumidores nos módulos donos. Sem eles, o ERP não chega à carteira, ao catálogo nem ao financeiro.

## Inventário (02/11)
| Evento | Dono | Situação |
|---|---|---|
| `integracao.cliente.atualizado@1` | core | consumidor novo (`consumidores-erp.ts`), só o cadastro do cliente; faltam carteira, contatos e financeiro (limite, saldo, bloqueio) |
| `integracao.produto.atualizado@1` | core | declarado no manifest, **sem consumidor** |
| `integracao.vendedor.atualizado@1` | core | **sem consumidor** (usuário vendedor e equipe) |
| `integracao.titulo.atualizado@1` | core | **sem consumidor** (títulos do Cliente 360) |
| `integracao.rota.atualizado@1` | core | **sem consumidor** (rota e paradas) |
| `integracao.nota.atualizado@1` | core (histórico de compra) / vendedor (faturamento) | **sem consumidor**; o faturado do pedido vem pelo `pedido.retorno_erp@1` (T-0054) |
| `integracao.preco.atualizado@1`, `integracao.estoque.atualizado@1` | catalogo | declarados no manifest; implementação a conferir |
| `integracao.produto_unidade` / `cliente_endereco` / árvore / transportadora / medida | core, catalogo, vendedor | eventos ainda não existem no contrato da Integração (R-20261102-124545; T-0061/T-0063) |
