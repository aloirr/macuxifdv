# T-0004 — Shells mobile (campo/gestao), web e api montando módulos pelo manifesto

## Objetivo
`apps/mobile` com variantes `campo` e `gestao` (nome, ícone, módulos possíveis), `apps/web` e `apps/api` carregando apenas módulos efetivos; registro de extensões de UI funcionando com um exemplo.

## Critérios de aceite
1. Dois builds Android de desenvolvimento gerados a partir do mesmo código, via **build de desenvolvimento do EAS** (perfis `campo` e `gestao` no `eas.json`, APK), sem Android SDK local; Expo Go só para iteração rápida (decisão do Alexandre, 2026-10-31)
2. Extensão de exemplo aparece só com o módulo ativo
3. Shells instalam os 8 módulos (a T-0001 ligou só core e vendedor) e `apps/api` tem `createApp` montando as rotas dos módulos efetivos

## Pendências herdadas da T-0002
Ver `docs/desenho/T-0002.md` §6: despacho da outbox entre tenants (papel `macuxi_worker`), índice `carteira_usuario_sync_ix`, cursor do pull (transação longa pode gravar `updated_at` atrás do cursor; definir estratégia) e nome do tenant no login.

## Premissas
- Stack e estrutura conforme `docs/produto/04-arquitetura-e-dados.md`.
