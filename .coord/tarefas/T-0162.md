# T-0162 — Kit do piloto

Origem: R-20261111-191644-alexandre, item 3. Começa **depois do BUILD PRONTO da v1.0.4**.

## Objetivo
O notebook do dono do produto vira um ERP simulado para o piloto, com o Conector instalado e falando com https://api.macuxifdv.com.br.

## Critérios de aceite
1. **Planilhas-modelo** com os dados do piloto: clientes, produtos, preços, estoque, filiais e títulos.
2. **Script para SQL Server 2022 Express**, que cria:
   - as tabelas;
   - as views `vw_macuxi_*`, a partir de `db/conector/views-modelo.sql`;
   - a entrada de pedidos, a partir de `db/conector/entrada-pedido-modelo.sql`;
   - o usuário restrito do Conector, só com SELECT nas views e INSERT na entrada.
3. **`conector.json` pronto** para https://api.macuxifdv.com.br. A chave é cadastrada no portal pelo dono do produto e nunca fica no kit.
4. **Roteiro curto de instalação no Windows**, em passos, para o dono do produto executar sozinho.
5. O script roda limpo duas vezes seguidas (idempotente). O teste usa o SQL do kit no CI, se der; se não der, uma conferência estática.

## Ordem e agentes
1. modulo-integracao — script, `conector.json` e roteiro
2. banco-dados — revisão das views e do usuário restrito
3. testes e corretor-redundancias — validação
4. engenheiro-software — revisão final

## Premissas
- Sem segredo no kit. O SQL Server é a edição Express 2022, local.
