# T-0178 — Trocar senha no Perfil

Origem: repasse da ponte às ~9h46 de 15/11/2026. O pedido é do dono do produto, para depois da v1.0.12.

## Objetivo
O usuário troca a própria senha pela tela Perfil (app Campo, app Gestão e BKO). Para isso, o core expõe a API.

## Critérios de aceite (a detalhar depois da simulação)
1. Antes de qualquer código, o designer-ux faz a simulação em PNG da tela "Trocar senha" no Perfil, e o dono do produto aprova.
2. A API do core para trocar a própria senha:
   - exige a senha atual;
   - aplica a política de senha que já existe;
   - mantém o hash argon2;
   - grava auditoria;
   - não registra dado pessoal em log.
3. Depois da troca, as outras sessões do usuário são encerradas. A forma exata fica com o engenheiro-software.
4. A troca de senha funciona só online. Offline, a tela mostra um aviso claro.
5. Testes cobrindo senha atual errada, senha fraca, multi-tenant e auditoria.

## Ordem
Começa só depois que a filial (T-0176) e o Código FDV (T-0175) entrarem no `main`.
