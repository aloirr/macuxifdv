# T-0080 — Positivação do mês com o Vendedor desligado

Origem: decisão do Alexandre (opção 3, pendência do PR #84) e a revisão do engenheiro-software de 05/11 (R-20261105-015906): a gravação de `core.indicador_diario` por `vendedor.pedido.status_alterado@1` atende só o Vendedor ligado; com o Vendedor desligado não há fonte.

## Objetivo
Com o Vendedor desligado, o Início mostra a positivação acumulada do mês (clientes distintos, sem repetir entre dias) a partir das notas faturadas que chegam do ERP pela integração.

## Critérios de aceite
1. Regra no domain do Core (função pura, teste antes): cliente positivado no mês = cliente com nota faturada (não cancelada) no mês, no fuso do tenant, contado uma vez; nota cancelada depois retira o cliente se ele não tiver outra nota no mês.
2. Fonte (decisão P1 do gerente, 05/11 02h20): `core.nota_erp` lida na hora da consulta (RN-CORE-27, docs/desenho/T-0080.md), atribuída pelo `vendedor_external_id` da nota (migração 0025 do banco-dados) — sem ler tabela de outro schema e sem cópia no `core.indicador_diario`.
3. Com o Vendedor ligado, continua valendo a fonte do Vendedor (sem contar duas vezes o mesmo cliente se as duas fontes existirem).
4. Multi-tenant isolado; idempotente; teste de banco no CI.

## Ordem e agentes
1. engenheiro-software — desenho curto (fonte, precedência entre Vendedor e ERP, colunas necessárias).
2. banco-dados — coluna/índice em `core.nota_erp` ou equivalente, se o desenho pedir.
3. modulo-core — domain e consumidor.
4. testes — validação. 5. engenheiro-software — revisão.

## Premissas (para o Alexandre confirmar)
- Positivação do mês com Vendedor desligado = cliente com nota faturada no mês (fuso do tenant), contado uma vez.
