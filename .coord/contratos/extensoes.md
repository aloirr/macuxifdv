| Extensão | Oferece | Usado por |

| `visita.etapas_checkout` | core | pesquisa, promotor, vendedor (motivo de não-venda) |

| `menu.itens` | core | todos |
| `produto.acoes` | catalogo | vendedor |
| `pedido.criar_em_nome` | vendedor | gestor |
