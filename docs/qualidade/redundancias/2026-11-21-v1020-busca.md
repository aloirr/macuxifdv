## 1. Ciclos do dependency-cruiser (aviso do testes)
`packages/config/dependency-cruiser.cjs` usa `tsPreCompilationDeps: true`, por isso o `import type` também conta. A regra `ciclo-entre-arquivos` tem severidade `warn` e manda "quebre extraindo o trecho comum". Os 3 ciclos novos nascem de uma linha só, `domain/veiculos.ts:11` (`import type { ProdutoCatalogo } from './vitrine'`):
- `veiculos → vitrine → veiculos`;
- `veiculos → vitrine → ranking → veiculos`;
- `veiculos → vitrine → serve-em → ranking → veiculos`.

O `veiculos.ts` só lê `nome`, `descricao`, `aplicacao` e `ativo`. Com um tipo estrutural próprio, os 3 ciclos caem. Esse mesmo tipo resolve a "fonte do produto", que hoje está montada em 3 lugares (RD-2495).

## 2. Núcleo do n-grama
A troca pedida foi feita: `coladas` (`ranking.ts:142`) é o núcleo único do n-grama colado, e `codigosDaConsulta` e `paresColados` só filtram o resultado. Não há outra cópia do laço. O que sobrou repetido está ao redor dele: o mínimo de 3 e a classe "só letras" foram escritos duas vezes (RD-2496).
