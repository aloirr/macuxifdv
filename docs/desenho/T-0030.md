## D-B29 — Auditoria na API nova
- Rota de plataforma `GET /v1/auditoria` (`apps/api/src/auditoria.ts`), contrato em `@macuxi/platform-sdk` (`auditoria.ts`):
  `AuditoriaQuerySchema` (`modulo?`, `entidade?`, `limite` 1..300 padrão 100, `cursor?`) e `AuditoriaRespostaSchema`
  (`itens[]` com `id, modulo, acao, entidade, entidade_id, usuario_id, usuario_nome, antes, depois, ocorrido_em` + `proximo_cursor`).
- Checagens: 401 → perfil (`PERFIS_AUDITORIA` = admin, analista, assistente, gerente; senão 403 PERFIL_SEM_ACESSO) → Zod 400
  → licença: `modulo` pedido fora dos efetivos = 403 MODULO_INATIVO; sem `modulo`, só linhas dos módulos efetivos (RN-CORE-01/02)
  → escopo: perfis de escopo `tenant` veem tudo; gerente só autores de `ctx.usuariosVisiveis()` (RN-CORE-04), sem linhas de sistema.
- SQL só em `plataforma.auditoria` com `comTenant` (RLS). Nome do autor por `core.cadastro_resumo@1` (ADR 0012), chamado pela
  plataforma direto no registro de consultas (não há `usaConsultas` para rota de plataforma). Ordem `ocorrido_em` (ms) desc, `id` desc;
  cursor `<ISO>_<uuid>`.
- Quem grava: `tx.auditar` (T-0029 E2) e o `auditar` do Core. A página `apps/web/components/audit/audit-page.tsx` usa `useAuditoria`.
- Pendente fora do shell: `modules/vendedor/web/lib/queries.ts` ainda chama `/audit-log` (painel de Alçadas, T-0029) — recado ao modulo-vendedor.

## Job de e2e no CI (registrado, não ligado)
Job separado `e2e-bko` em `.github/workflows/ci.yml`, depois de `verificar`, só em `pull_request` e `push` ao `main`:
1. `services: postgres` (mesma imagem do `docker-compose.yml`) e `pnpm install --frozen-lockfile`;
2. `pnpm db:migrar` + seed `demo` (`db/seeds/demo`), API em 8100 (`apps/api` com `MACUXI_*` do `.env.example`) em segundo plano;
3. `pnpm --filter web build && pnpm --filter web start` em segundo plano (porta 3000; `next start`, não `next dev`);
4. `npx playwright install --with-deps chromium` e `MACUXI_PW_CANAL= pnpm test:e2e` (no runner não há Chrome do usuário);
5. artefato `test-results/` (traces) em falha. Tempo estimado: 6–8 min. Ligar quando a matriz não tiver mais `test.fail` instável.
