# T-0181 — Frases da tela de carga: contrato (SDK e rotas)

> 2026-11-15 · engenheiro-software. Spec aprovada: `docs/design/carga-aviso-frases/` (commit `3cdb384`, `spec.md` §2 a §4 e
> `frases.md`). A tela (aviso, `cabeFrase`, sorteio) e o portal são do engenheiro-apps; a migração 0082 é do banco-dados.

## 1. SDK — `packages/platform-sdk/src/frase-carga.ts`
- `FRASE_CARGA_MAX = 90` (pontos de código depois do trim, como o `char_length` do Postgres).
- `FraseCargaSchema { id uuid, numero int > 0, texto (trim, 1..90), ativa bool, ordem int }` · `FrasesCargaListaSchema { itens }`.
- `FraseCargaEntradaSchema { id?: uuid, texto }` (`.strict()`; texto cru até 1000 → a regra decide). O `id` é opcional e torna o
  reenvio idempotente; sem ele, a API gera.
- `FraseCargaAlteracaoSchema { texto?, ativa? }` (`.strict()`, pelo menos um).
- `FraseCargaAppSchema { id, texto, ordem }` · `FrasesCargaAppRespostaSchema { frases }` (o app). Nenhum contrato tem a fonte.
- `validarTextoFrase(texto, existentes?, idProprio?)`: trim; vazio → `FRASE_VAZIA` "Escreva a frase."; > 90 → `FRASE_LONGA`
  "Use até 90 caracteres."; repetida sem diferenciar maiúsculas (a própria não conta) → `FRASE_DUPLICADA` "Essa frase já está
  na lista.". `chaveFraseCarga` = `lower(btrim(texto))`. `ordenarFrasesDoPortal`: ativas pelo Nº, inativas no fim.
- Rotas: `ROTA_PORTAL_FRASES_CARGA = '/v1/plataforma/frases-carga'`, `ROTA_SYNC_FRASES_CARGA = '/v1/sync/frases-carga'`.
- `FRASES_CARGA_INICIAIS`: as 30 do `frases.md`, Nº = ordem = 1..30, todas ativas. **Id do Nº n =
  `plataforma.uuid_de_chave('plataforma:frase_carga:' || lpad(n::text, 2, '0'))`** (função da 0005). Nº 1 →
  `30db8593-800a-56dc-98dc-b8976806ace5`; a lista literal completa está no arquivo (`INICIAIS`), e o teste recalcula os 30.

## 2. API — `apps/api/src/frases-carga.ts` (sempre ligada; antes da 0082, 503 `FRASES_CARGA_INDISPONIVEIS`)
| Rota | Quem | Função do banco | Resposta |
|---|---|---|---|
| `GET /v1/plataforma/frases-carga` | super-admin (cliente 403) | `sa_listar_frases_carga(sid)` | 200 `{ itens }` na ordem do banco |
| `POST /v1/plataforma/frases-carga` | super-admin | `sa_incluir_frase_carga(sid, id, texto)` | 201 `FraseCarga` |
| `PATCH /v1/plataforma/frases-carga/:id` | super-admin | `sa_editar_frase_carga(sid, id, texto, ativa)` | 200 `FraseCarga` |
| `GET /v1/sync/frases-carga` | sessão do app, qualquer perfil, sem licença de módulo | `frases_carga_ativas()` | 200 `{ frases }` na ordem do banco |

Portal na conexão `macuxi_portal`, `marcarPortal` audita a requisição, `Cache-Control: private, no-store`. Sem DELETE.
Erros: 422 `FRASE_VAZIA`/`FRASE_LONGA` (SDK, antes do banco) e `FRASE_DUPLICADA` (23505); 404 `FRASE_NAO_ENCONTRADA` (P0002);
401 (28000); 403 `PERFIL_SEM_ACESSO` "Só o time da Macuxi cuida das frases da carga." (cliente ou 42501); 400 (22023/23514); 503 (42883/42P01). Log sem o texto das frases.
