# T-0174 — Frases da tela de carga: contrato (SDK, rotas, funções do banco)

> 2026-11-15 · engenheiro-software. Spec aprovada: `docs/design/carga-aviso-frases/` (commit `3cdb384`, `spec.md` §2 a §4 e
> `frases.md`). A tela (aviso, `cabeFrase`, sorteio) e o portal são do engenheiro-apps; a migração 0075 é do banco-dados.

## 1. SDK — `packages/platform-sdk/src/frase-carga.ts`
- `FRASE_CARGA_MAX = 90` (pontos de código depois do trim, como o `char_length` do Postgres).
- `FraseCargaSchema { id uuid, numero int > 0, texto (trim, 1..90), ativa bool, ordem int }` · `FrasesCargaListaSchema { itens }`.
- `FraseCargaEntradaSchema { id?: uuid, texto }` (`.strict()`; texto cru até 1000 → a regra decide). O `id` é opcional e torna o
  reenvio idempotente; sem ele, a API gera.
- `FraseCargaAlteracaoSchema { texto?, ativa? }` (`.strict()`, pelo menos um).
- `FraseCargaAppSchema { id, texto, ordem }` · `FrasesCargaAppRespostaSchema { frases }` (o app). Nenhum contrato tem a fonte.
- `validarTextoFrase(texto, existentes?, idProprio?)`: trim; vazio → `FRASE_VAZIA` "Escreva a frase."; > 90 → `FRASE_LONGA`
  "Use até 90 caracteres."; repetida sem diferenciar maiúsculas (a própria não conta) → `FRASE_DUPLICADA` "Essa frase já está
  na lista.". `chaveFraseCarga` = `lower(btrim(texto))`. `ordenarFrasesDoPortal`: ativas pelo Nº, inativas no fim.
- Rotas: `ROTA_PORTAL_FRASES_CARGA = '/v1/plataforma/frases-carga'`, `ROTA_SYNC_FRASES_CARGA = '/v1/sync/frases-carga'`.
- `FRASES_CARGA_INICIAIS`: as 30 do `frases.md`, Nº = ordem = 1..30, todas ativas. **Id do Nº n =
  `plataforma.uuid_de_chave('plataforma:frase_carga:' || lpad(n::text, 2, '0'))`** (função da 0005). Nº 1 →
  `30db8593-800a-56dc-98dc-b8976806ace5`; a lista literal completa está no arquivo (`INICIAIS`), e o teste recalcula os 30.

## 2. API — `apps/api/src/frases-carga.ts` (sempre ligada; antes da 0075, 503 `FRASES_CARGA_INDISPONIVEIS`)
| Rota | Quem | Função do banco | Resposta |
|---|---|---|---|
| `GET /v1/plataforma/frases-carga` | super-admin (cliente 403) | `sa_listar_frases_carga(sid)` | 200 `{ itens }` ordenado |
| `POST /v1/plataforma/frases-carga` | super-admin | `sa_incluir_frase_carga(sid, id, texto)` | 201 `FraseCarga` |
| `PATCH /v1/plataforma/frases-carga/:id` | super-admin | `sa_editar_frase_carga(sid, id, texto, ativa)` | 200 `FraseCarga` |
| `GET /v1/sync/frases-carga` | sessão do app, qualquer perfil, sem licença de módulo | `frases_carga_ativas()` | 200 `{ frases }` pela ordem |

Portal na conexão `macuxi_portal`, `marcarPortal` audita a requisição, `Cache-Control: private, no-store`. Sem DELETE.
Erros: 422 `FRASE_VAZIA`/`FRASE_LONGA` (SDK, antes do banco) e `FRASE_DUPLICADA` (23505); 404 `FRASE_NAO_ENCONTRADA` (P0002);
401 (28000); 403 (42501); 400 (22023/23514); 503 (42883/42P01). Log sem o texto das frases.

## 3. Banco — migração 0075 (banco-dados), assinaturas que a API chama
Padrão da 0058: `plataforma.sa_sessao_valida(p_sid)`; sessão inválida = 28000; não super-admin = 42501; `SECURITY DEFINER`,
`set search_path`, `revoke all ... from public, macuxi_app, macuxi_worker`, `grant execute ... to macuxi_portal`; auditoria
da mudança (incluir/editar) na trilha do super-admin, sem o texto se a trilha não comportar.
- `plataforma.sa_listar_frases_carga(p_sid uuid) returns jsonb` → `{ "itens": [{ id, numero, texto, ativa, ordem }] }` (vivas).
- `plataforma.sa_incluir_frase_carga(p_sid uuid, p_id uuid, p_texto text) returns jsonb` → a frase. Nasce ativa;
  `numero = max(numero)+1`, `ordem = max(ordem)+1` (com trava contra corrida). Mesmo `p_id` já gravado com o mesmo
  `lower(btrim(texto))` → devolve a existente (idempotente); texto repetido de outra → 23505; texto fora de 1..90 → 23514.
- `plataforma.sa_editar_frase_carga(p_sid uuid, p_id uuid, p_texto text, p_ativa boolean) returns jsonb` → a frase depois.
  Nulo = não muda; sem achar (ou apagada) → P0002; repetida → 23505. Substitui a `sa_ativar_frase_carga` do rascunho do gerente.
- **Leitura do app (escolha):** função `plataforma.frases_carga_ativas() returns jsonb` → `{ "frases": [{ id, texto, ordem }] }`
  só `ativa and deleted_at is null`, `order by ordem, numero`; `SECURITY DEFINER`, `stable`, `grant execute to macuxi_app`.
  Motivo: a tabela é global (sem `tenant_id`) e a leitura fica no mesmo padrão de `dados_legais_publicos()`, sem policy de
  select nova para o `macuxi_app` e sem expor as inativas. A API chama dentro do `ctx.comTenant` da requisição.
- Seed idempotente das 30 com os ids da §1 (`on conflict (id) do nothing`); o teste do banco confere contra `FRASES_CARGA_INICIAIS`.
