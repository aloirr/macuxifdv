```
                                                             │
                     testes + corretor (prints) + design-de-marca + revisão ─► M3 ─► ensaio ─► BUILD PRONTO demo
```

**Caminho crítico:** M0 → N-D (servidor, nuvem) → costura do Core no PC → Início e Perfil → testes no aparelho → corretor
pelos prints → correções → revisão final → ensaio → build. O **modulo-core** é o gargalo do PC: por isso as telas novas, o BKO
e o servidor da T-0170 vão para a nuvem em arquivos novos, e o PC faz só a costura.

**Em paralelo, sem colisão:** F (Catálogo) com D e E; G4 com tudo; G2 começa antes do M1 sobre as notificações de hoje; N-A, N-B,
N-C e N-G começam agora.
