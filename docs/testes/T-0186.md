## Defeitos

- **D-T0186-1** (E-01, E-04, E-05b): os consumidores liam `forma_pagamento_codigo`; o contrato do Hub manda `forma_pagamento`.
  Corrigido no core `c0823a0e` (verde).
- **D-T0186-2** (D-04): o Core não implementava `ModuloApi.guardaArquivo`. Corrigido no core `c0823a0e` (verde).
- **D-T0186-3** (P-06): `inicioDoPeriodoNf('12m', '2028-02-29')` devolve `2027-02-29`. Arquivo:
  `modules/core/domain/historico-nf.ts` (`inicioDoPeriodoNf`). Dono: `modulo-core`. Aberto.
- **D-T0186-4** (bloqueia o lote): o core chama `creditoDisponivel({ financeiro, pedidos_aprovados })` e importa
  `PedidoQuePesaNoCredito`, mas o vendedor `d13b5177` mudou o contrato para `{ financeiro, pedidos }` e `PedidoDoCliente`.
  O `typecheck:tests` quebra e, em execução, `i.pedidos.filter` lança TypeError: o GET /v1/core/clientes/:id dá 500
  (carteira-escopo, cliente360-offline, pagamento-t0089, demo-matriz e 14 casos do `@macuxi/core`). Arquivos:
  `modules/core/domain/historico-nf.ts:9,90` e `modules/core/app/lib/ficha-v2.ts:19`. Dono: `modulo-core`.
- **D-T0186-5**: `apps/conector/test/exemplos-views-modelo.test.ts` — o exemplo do Conector não mapeia os campos novos do
  título (`nf_numero`, `nf_serie`, `forma_pagamento`). Arquivo: `apps/conector/exemplos/conector.exemplo.json`. Dono:
  `modulo-integracao`.
