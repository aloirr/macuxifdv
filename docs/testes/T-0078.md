## Defeitos
- **D-L1a** — `apps/api/src/app.ts` (`setErrorHandler`: `req.log.error({ err: erro }, 'erro não tratado')`) e
  `apps/api/src/conector.ts` (mesmo padrão): o serializador de erro do pino copia todas as propriedades do erro; um
  `DatabaseError` do pg que sobe sem tratamento leva `detail` ("Key (tenant_id, email)=(…, e-mail) already exists",
  "Failing row contains (…)") ao log. Reproduzir: caso `D-L1a` (trocar `it.fails` por `it`). Dono: engenheiro-software.
- **D-C1a** — `scripts/carga/sync-basico.mjs` faz login em `/v1/core/auth/login`; a rota do Core é `/v1/auth/login`
  (`modules/core/api/index.ts`, `montarRotaPublica`). Contra a API real sai com "login falhou (status 404)". Os testes de
  carga usam um repasse de compatibilidade até a correção. Dono: engenheiro-software.
