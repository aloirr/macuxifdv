## Teste manual (aparelho real, build com a T-0090)

1. Gestão, Pedidos: abrir a folha, escolher um vendedor; digitar um nome na busca → o resumo diz "N resultados · <vendedor> · últimos 90 dias" e a etiqueta do vendedor aparece abaixo; tocar o ✕ → resumo sem vendedor e lista de todos.
2. Campo, Início → card "A faturar": a lista abre com o chip A faturar; abrir a folha e tocar "Mês passado" → o chip A faturar some, Todos fica ativo, etiqueta "Mês passado ✕". Repetir com o card de orçamentos em aberto.
3. TalkBack ligado: a etiqueta do vendedor é lida "Remover filtro <nome>".
4. Modo avião, escolher um mês de mais de 90 dias atrás → vazio "Sem sinal: este período não está no aparelho. Os pedidos aparecem quando o sinal voltar."; ligar o sinal → a lista vem do servidor (anotar se veio sozinha ou só depois de puxar para baixo: a promessa do texto é "quando o sinal voltar").
